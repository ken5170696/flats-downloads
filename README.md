# FLATS player downloads

This repository distributes approved public **player binaries** through [Releases](https://github.com/ken5170696/flats-downloads/releases).

Use the [official download page](https://flats-site.tail2511fc.ts.net/downloads?lang=en) for current platform availability, version, size, SHA-256 and limitations. Downloads are anonymous; no GitHub account or Tailscale installation is required.

Windows packages are unsigned test builds. Extract the complete ZIP and retain the Data and runtime folders. Read the release-specific runtime status before use.

The development repository and its history remain private. GitHub's automatically generated **Source code** archives for this repository contain distribution documentation only; they are not the game installer or development source.

Versioned assets are never overwritten. Releases record their size and SHA-256. The manually triggered verification workflow downloads only public release files from a standard hosted runner; it has read-only permissions, no deployment credentials, and no access to private source.
